How to read this

Locked
No master key exists, so no single person can swap the token's code.
Master key held
Someone holds a key that can replace the token's code at any moment.
Code fingerprint
A short ID of the token's code. If it changes, the rules changed.
Top 10 hold
Share of supply held by the 10 largest accounts. These are often pools, bridges and exchanges, not people, so a high number is normal for big tokens.
